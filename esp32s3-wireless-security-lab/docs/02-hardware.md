# 02 — Hardware Setup

## ESP32-S3

The ESP32-S3 is a dual-core microcontroller platform with Wi-Fi and Bluetooth Low Energy capabilities.

## Required equipment

- ESP32-S3 development board
- USB data cable
- Computer
- Test mobile device
- Authorized Wi-Fi test environment

## Initial checks

Before flashing firmware:

1. Connect the board with a USB data cable.
2. Check that the board appears as a USB/serial device.
3. Identify the correct COM/USB port.
4. Close applications that may already be using the port.
