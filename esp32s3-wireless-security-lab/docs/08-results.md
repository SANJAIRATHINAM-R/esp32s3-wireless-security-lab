# 08 — Results and Observations

## Firmware

The ESP32-S3 was identified and prepared for a compatible firmware installation.

## Wi-Fi

The lab demonstrated the basic workflow for discovering wireless networks and interpreting wireless information.

## Bluetooth/BLE

The experiment demonstrated how BLE advertisements can be observed from nearby test devices.

## Captive portal

A controlled local portal demonstrated how a mobile device can be presented with a network web page after joining a test network.

## Main learning

The most useful outcome was understanding the relationship between:

**Hardware → Firmware → Wireless interface → Mobile client → Security behaviour**
