# 01 — Introduction

## Why this project?

IoT devices increasingly combine embedded processors, wireless connectivity and web/mobile interfaces. Understanding their security requires practical experimentation.

This project explores an ESP32-S3 based platform as a learning tool for wireless and IoT security.

## Goals

1. Understand the ESP32-S3 setup process.
2. Learn how firmware is installed.
3. Explore Wi-Fi discovery in an authorized lab.
4. Explore Bluetooth Low Energy discovery.
5. Study controlled captive-portal behaviour.
6. Observe mobile-device interaction.

## Scope

The experiments are designed for a controlled laboratory environment. No unauthorized networks or devices are targeted.
