# 06 — Controlled Captive Portal Demonstration

## What is a captive portal?

A captive portal is a web page presented to a device after it connects to a network. It is commonly used in legitimate public Wi-Fi environments for terms, access or authentication.

## Lab demonstration

For this project, the concept is demonstrated using a controlled test environment.

The purpose is to observe:

1. Device connects to the test network.
2. The network redirects the client toward a local web page.
3. The mobile browser displays the test page.
4. The behaviour is recorded for learning.

No real credentials should be collected.
