# 09 — Ethical and Responsible Use

Wireless-security tools are dual-use technology.

## Rules for this project

- Test only equipment and networks you own or are authorized to assess.
- Use isolated lab networks for experiments.
- Never collect credentials from other people.
- Never intentionally disrupt third-party networks.
- Never impersonate trusted services to deceive users.
- Keep test data local and remove it when no longer needed.
- Document authorization and scope before testing.

The purpose of this project is education, defensive security research and responsible IoT experimentation.
