## 🧰 Requirements

- ESP32-S3 development board
- USB data cable
- Windows or Linux computer
- Compatible firmware
- Android or iOS test device
- Authorized test Wi-Fi network

## ⚙️ Firmware Setup

1. Connect the ESP32-S3 to your computer.
2. Identify the correct USB/COM port.
3. Open the compatible GhostESP web flasher.
4. Select the ESP32-S3 target.
5. Enter bootloader mode if required.
6. Select firmware compatible with your board.
7. Follow the flashing tool's instructions.
8. Wait for flashing to complete.
9. Restart the device and verify that it boots.

**Note:** Erasing flash removes existing firmware and data. Confirm your board and firmware selection before proceeding.

This project explores captive-portal behaviour using a controlled local demonstration to understand how mobile devices interact with network pages.

## 🔐 Ethical Use

This project is intended for educational purposes and authorized cybersecurity research.

- Test only devices and networks you own or have permission to assess.
- Do not collect other people's credentials.
- Do not disrupt third-party networks.
- Do not impersonate trusted services to deceive users.
- Use controlled lab environments for demonstrations.

Documentation describes the intended learning process and does not claim that every feature has been independently verified on every device.
